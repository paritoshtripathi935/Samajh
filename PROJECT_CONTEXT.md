# Samajh Project Context

Samajh is intended as a one-stop platform primarily for individual lawyers.

## Primary User

- Individual lawyers

## Priority Features

- P0: Filing Understanding
  - Digitising raw legal documents
  - Chat over filings
  - Citations, including references such as IPC dharas
- P0: Research Workbench
  - Research across documents
  - Artifact creation
- P2: Case Management
  - Multiple clients
- P2: Client-facing experience

## Initial Document Types

- Chargesheets
- Judgment orders
